Cleo

Cleo is a private AI assistant that helps its owner and approved household users organize information, prepare email drafts, manage appointments, and work with documents.

Google connections

  • Gmail: read an explicitly connected assistant inbox and prepare unsent drafts in an explicitly authorized account. The owner's drafting connection does not provide inbox-reading or email-sending permission.
  • Google Calendar: read calendars and create or update events when the user authorizes scheduling.
  • Google Drive, Docs and Sheets: retrieve and work with documents in connected accounts, subject to granted permissions. A separate authorized Drive connection supports backups.

Access requires the account holder's Google authorization. Features depend on the permissions actually granted and on a working connection; this page does not indicate that any account is currently connected.

This is not a public signup service. The assistant and its controls remain private; these pages explain the application and its data practices.
